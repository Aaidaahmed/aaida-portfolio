PROJECT 01 / PROCESSOR DESIGN

RV32I RISC-V Processor

A Verilog RTL implementation of a single-cycle RISC-V processor, featuring a custom multiply-accumulate execution unit, memory-mapped GPIO and performance counters.

01 / OVERVIEW

Inside the processor.

This project implements a single-cycle RISC-V processor datapath in Verilog. The design brings together instruction fetching, decoding, execution, memory access and register write-back within a single-cycle architecture.

The processor also incorporates a custom multiply-accumulate (MAC) execution unit, memory-mapped GPIO and performance counters to monitor processor activity.

02 / ARCHITECTURE

Processor architecture.

The processor follows a single-cycle datapath organization. Its RTL is divided into modules responsible for computation, control, memory and peripheral functionality.

Program Counter & Instruction Memory

Maintains instruction sequencing and supplies instructions for execution.

Instruction Decoder & Immediate Generator

Interprets instruction fields and generates the required immediate values.

Register File & ALU

Provides source operands and performs arithmetic and logical operations.

Branch Unit & Data Memory

Handles branch decisions and load/store memory operations.

Custom Execution & Peripheral Units

Integrates MAC execution, GPIO access and performance monitoring.

03 / INSTRUCTION WALKTHROUGH

Follow an instruction.

Here's how a load-word instruction travels through the processor, from instruction fetch to register write-back.

LW x10, 0(x1) Load Word
01

Fetch

The PC supplies the instruction address.

02

Decode

The decoder identifies the load operation and destination register.

03

Read operands

The register file supplies x1 and the immediate generator extracts the offset.

04

Calculate

The ALU computes the effective memory address.

05

Load

Data memory returns the requested word.

06

Write-back

The loaded value is written into x10.

04 / SIMULATION
